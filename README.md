## 正在孵化

### 原生 macOS 菜单栏 AI 文本处理工具

我想把常用的 AI 文本操作，变成一套自然、连贯的系统级快捷流：

```text
选中文本  →  捕获  →  AI 处理  →  结果写回
```

它会专注于润色、翻译、总结、格式转换等高频场景，并尽量减少在不同应用之间来回切换的打断。项目正在筹备中，计划开源。
